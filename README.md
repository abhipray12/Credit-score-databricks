# 🏦 Credit Score Pipeline with Databricks (Community Edition)

A complete, rule-based credit scoring project using PySpark and Delta Lake tables, implemented in a single notebook on Databricks Community Edition. Simulates a data engineering workflow with Bronze → Silver → Gold layers.

---

## 🚀 What This Project Does

✅ Simulates raw customer credit data  
✅ Applies transformations and validations (Silver layer)  
✅ Implements credit scoring logic (Gold layer)  
✅ Assigns risk categories (Excellent, Very Good, etc.)  
✅ Generates summary statistics and visual insights  

---

## 🛠 Tech Used

- Databricks Community Edition
- PySpark (Spark SQL, DataFrames)
- Delta Lake (internal tables)
- Notebook-based workflow

---

## 📁 Project Structure

| Layer    | Purpose                          |
|----------|----------------------------------|
| Bronze   | Raw ingested data                |
| Silver   | Cleaned & validated data         |
| Gold     | Scored credit profiles + insights|
